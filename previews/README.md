# 마인디 3D 미리보기

`../mindly-3d-preview.html`을 Chrome 또는 Edge에서 더블클릭해 열면 세 시안을 전환할 수 있습니다. 아래 개별 파일도 각각 혼자 열립니다. 서버·인터넷·로그인이 필요하지 않습니다.

- `01-sunlit-room.html`: 햇살 드는 상담실
- `02-letters-of-care.html`: 마음을 전하는 편지
- `03-quiet-journal.html`: 고요한 밤의 기록

캐릭터는 `assets/mascot.png`의 실제 윤곽과 표면을 사용하는 **입체 부조 방식**입니다. 원본의 자세, 색과 무늬, 모자와 가방을 보존하면서 둥근 두께와 뒷면을 생성합니다. 원본에 없는 입을 추가하지 않습니다. 단일 정면 이미지에 없는 뒷모습을 임의로 재창작하지 않으므로 관찰 각도를 좌우 약 23도로 제한했습니다.

재생 버튼 없이 자동으로 움직입니다. 드래그 또는 방향키로 각도를 바꿀 수 있고, Home 키로 원래 각도로 돌아옵니다. 캐릭터를 누르면 미세하게 고개를 끄덕입니다. 동작 줄이기 설정과 숨겨진 탭에서는 자동 모션을 멈춥니다.

1번 시안은 실제 앱의 기본 화면에, 3번 시안은 나이트 모드에 적용되어 있습니다. 실제 앱에서는 기존 오른쪽 하트 말풍선도 함께 표시합니다. 이 독립 미리보기 파일에는 Firebase, 분석 도구, 외부 요청이 없습니다.

소스를 수정한 뒤 다음 명령으로 네 HTML 파일을 함께 갱신합니다.

```sh
node scripts/build-3d-previews.mjs
```

`../visuals/mindy-character.js`는 원본 표면과 입체 형상을, `../visuals/mindy-stage.js`는 세 장면과 모션을 구성하며 실제 앱과 공유합니다. `source/preview.js`, `source/preview.css`, `source/shell.html`은 독립 비교 화면을 구성합니다. Three.js와 원본 이미지는 각 HTML에 포함됩니다.
