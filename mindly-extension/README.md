# 마인들리 크롬 확장 프로그램

선택한 댓글을 모아 상황·주제·쟁점·찬반 입장과 근거를 확인하고 기존 마인들리 토론으로 이어갑니다. 유튜브에서는 작성 중인 댓글의 표현을 검토하고 승인한 수정문만 입력창에 적용합니다. 댓글을 게시하지 않습니다.

## 처음 설치하기

1. 크롬 주소창에 `chrome://extensions`를 입력합니다.
2. 오른쪽 위 **개발자 모드**를 켜고 **압축해제된 확장 프로그램을 로드합니다**를 누릅니다.
3. 이 README가 있는 `mindly-extension` 폴더를 선택합니다. ZIP으로 받았다면 먼저 압축을 풀고 `manifest.json`이 들어 있는 폴더를 선택합니다.
4. 크롬의 퍼즐 모양 확장 프로그램 메뉴에서 마인들리의 핀을 켭니다.
5. 마인들리 웹사이트에서 기존 계정으로 로그인합니다. AI 요청에 이 탭을 사용하므로 열어 둡니다.

폴더의 코드를 갱신하면 `chrome://extensions`에서 마인들리 카드의 새로고침을 누릅니다. 열려 있던 유튜브·마인들리 페이지도 새로고침합니다.

## 댓글에서 토론으로

1. 유튜브·뉴스·커뮤니티에서 댓글을 드래그합니다.
2. 우클릭 → **마인들리에 선택한 댓글 모으기**를 누릅니다. 다른 의견도 같은 방법으로 모을 수 있습니다.
3. 마인들리 패널에서 가져온 글의 개인정보를 지우고, 필요한 경우 문맥을 덧붙입니다.
4. AI 전송 동의를 체크하고 **상황과 양쪽 입장 살펴보기**를 누릅니다.
5. **마인들리에서 토론하기**를 누릅니다. 웹사이트에서 초안을 확인·수정한 뒤 직접 게시합니다.

확장 프로그램에는 짧은 주제, 찬성·반대 각 한 줄, 핵심 쟁점 1~2개만 표시합니다. AI가 내용을 짧게 요약하며 긴 문장을 중간에서 잘라 표시하지 않습니다. 배경 설명과 자세한 쟁점·입장은 마인들리 토론 초안에 유지됩니다. 버전 0.1.1로 새로고침한 뒤 다시 분석하면 간결한 요약을 볼 수 있습니다.

우클릭의 **선택한 댓글로 마인들리에서 토론하기**는 선택 글을 모은 뒤 웹사이트로 바로 전달합니다. 이 경우 웹사이트의 전용 가져오기 화면에서 전송 동의 후 분석합니다.

웹사이트에서 평소처럼 새 토론을 만들면 기존 사진 업로드·분석 화면을 사용합니다. 가져온 텍스트는 별도 화면에서 다루며 작성 중인 사진 토론을 덮어쓰지 않습니다.

가져온 토론 초안이 이미 있으면 다른 주제를 자동으로 덮어쓰지 않습니다. 해당 화면에서 **가져온 글 비우기**를 누른 뒤 다시 보냅니다. 동일 주제의 기존 게시물을 자동 추천하는 기능은 이 버전에 포함되지 않습니다.

## 유튜브 말투 교정

1. 패널 하단의 **연결과 설정 → 유튜브 교정 버튼 켜기**를 누르고 유튜브 접근 권한을 허용합니다.
2. 유튜브 댓글·답글 입력창에서 글을 작성하고 **마인들리 말투 다듬기**를 누릅니다.
3. 패널에서 원문과 전송 내용을 확인하고 AI 전송 동의 후 **말투 수정 제안 받기**를 누릅니다.
4. 제안을 확인한 뒤 **수정문을 유튜브 입력창에 적용**을 누릅니다.
5. 유튜브에서 직접 댓글을 게시합니다.

검사 후 입력창을 추가로 수정하거나 다른 영상으로 이동했다면 이전 제안을 덮어쓰지 않습니다. 현재 입력창에서 다시 가져와 검토합니다. 다른 사이트는 패널의 말투 입력란에 직접 붙여 넣어 사용할 수 있으며 입력창 적용은 유튜브만 지원합니다.

유튜브가 화면 구조를 바꾸면 입력창 옆 버튼을 수정해야 할 수 있습니다. 접근 권한은 설정에서 끌 수 있습니다.

## 연결 방식과 데이터

- 확장 프로그램 → 마인들리 탭의 제한된 연결 코드 → 기존 Cloudflare Worker → 기존 AI 제공자 순서로 요청합니다.
- 웹사이트의 Firebase 로그인과 서버 검증을 사용합니다. 계정 비밀번호, Firebase 토큰, AI 비밀 API 키를 확장 프로그램으로 전달하거나 저장하지 않습니다.
- 선택한 글과 사용자가 가져온 작성 중 댓글만 수집합니다. 전체 댓글·영상·기사·검색 기록은 자동 수집하지 않습니다.
- 페이지 제목과 정리한 출처 URL은 가져온 글과 함께 표시합니다. 출처는 AI에 보내거나 공개 토론 DB에 저장하지 않습니다. 추가 문맥은 사용자가 직접 입력합니다.
- 가져온 원문·수정 제안은 `chrome.storage.session`의 확장 프로그램 전용 저장소에 둡니다. 한 시간 동안 변경 없이 보관된 자료는 다음 접근 때 비우며, 브라우저를 종료하면 사라집니다. 설정의 비우기 버튼으로 즉시 삭제할 수 있습니다.
- AI 전송은 각 분석·검토 버튼의 전송 동의를 필요로 합니다. 전송 내용은 선택된 AI 제공자의 데이터 처리 정책을 적용받습니다. 원본을 자체 DB에 저장하지 않는다는 것이 AI 제공자까지 저장하지 않는다는 뜻은 아닙니다.
- 기존 사진 분석 한도와 텍스트 검사 한도를 사용합니다. 텍스트 분석·말투 교정은 사용자당 하루 글 검사 40회와 전체 AI 사용 제한에 포함됩니다.

기본 권한은 선택한 탭 접근, 우클릭 메뉴, 스크립트 실행, 확장 프로그램 전용 저장소, 사이드패널입니다. 상시 접근은 마인들리 서비스와 로컬 개발 주소로 한정하며 유튜브 접근은 사용자가 켤 때 요청합니다. 일반 사이트에서 페이지 이동 후 가져오기가 막히면 해당 페이지에서 확장 프로그램 아이콘을 다시 누르거나 우클릭 메뉴를 사용합니다.

## 운영 웹사이트와 서버에 반영하기

확장 프로그램만 설치해서는 새 AI 경로를 사용할 수 없습니다. 이 변경의 웹사이트 연결 코드와 Worker를 함께 반영해야 합니다. 기존 DB 구조와 Firestore 규칙은 변경하지 않습니다.

변경 파일:

- `../extension-bridge.js`: 로그인된 웹사이트에서 요청을 처리하고 전용 가져오기 화면을 표시합니다.
- `../index.html`, `../views.js`, `../app.js`, `../scripts/build-static.mjs`: 연결 코드 포함과 전용 화면 등록입니다.
- `../worker/src/index.js`, `../worker/src/ai.js`: `/v1/analyze-text`, `/v1/rewrite`와 관련 AI 검증입니다. 기존 `/v1/analyze` 사진 요청은 유지합니다.
- 이 폴더: 확장 프로그램 화면·글 수집·유튜브 입력창 연결입니다.

프로젝트 루트에서 `npm run build`로 웹 배포 파일을 만들고, 기존 GitHub Pages 배포 절차를 따릅니다. `worker` 폴더에서 `npm run deploy`로 Worker를 반영합니다. 새 DB 마이그레이션이나 별도 API 키는 필요하지 않습니다. 기존 AI 제공자의 키와 사용 가능 상태는 그대로 적용됩니다.

`UPDATE_REQUIRED`는 Worker 업데이트가 아직 반영되지 않은 경우입니다. `PAGE_NOT_READY`는 웹사이트 연결 코드가 없거나 페이지가 로딩 중인 경우입니다. `LOGIN_REQUIRED`는 열린 마인들리 탭에 로그인한 뒤 다시 실행합니다. AI 제공자 오류가 나오면 기존 관리자 화면에서 실제 연결을 확인합니다.

## 로컬 검증

운영 배포 없이 웹사이트와 AI 서버를 모두 컴퓨터에서 실행할 수 있습니다.

1. 프로젝트의 [start-extension-test.cmd](../start-extension-test.cmd)를 더블클릭합니다. 터미널을 사용한다면 프로젝트 루트에서 `npm run dev:extension`을 실행합니다. 이 실행 파일은 로컬 DB를 준비하고 웹사이트(4173)와 Worker(8787)를 함께 켭니다.
2. 크롬에서 `http://127.0.0.1:4173`을 열고 기존 계정으로 로그인합니다.
3. 위의 설치 방법으로 확장 프로그램을 불러오고 **연결과 설정 → 로컬 테스트 · 127.0.0.1**을 선택합니다.
4. 유튜브에서 댓글을 선택해 우클릭으로 모은 다음 **마인들리에서 토론하기**를 누릅니다. 로컬 웹사이트에 선택 글이 들어오는지 확인합니다.
5. 말투 교정 버튼을 켜고 작성 중인 댓글이 패널로 전달되는지 확인합니다. 종료하려면 실행 창에서 `Ctrl+C`를 누릅니다.

**실제 AI 분석과 말투 수정 제안까지 확인하려면:** 최초 실행 때 생성되는 `worker/.dev.vars`를 VS Code에서 열고 `GEMINI_API_KEY=""`의 따옴표 안에 사용 가능한 Gemini API 키를 넣습니다. 저장 후 실행 창에서 `Ctrl+C`로 종료하고 실행 파일을 다시 엽니다. 키는 채팅이나 `site-config.js`에 넣지 않습니다. Cloudflare 운영 비밀값은 로컬로 자동 복사되지 않습니다. 로컬에서도 AI 제공자의 사용 가능 상태와 한도는 적용됩니다.

키가 없으면 댓글 수집·전달·입력창 버튼까지만 확인할 수 있고, 실제 AI 분석·교정 요청은 `AI_NOT_CONFIGURED`로 중단됩니다. 모의 분석 결과를 실제 AI 응답인 것처럼 표시하지 않습니다.

이 모드는 토론 DB를 로컬에 따로 만들고, 실행 중에만 웹사이트의 API 주소를 로컬로 바꿉니다. 배포용 `site-config.js`와 운영 토론 DB는 변경하지 않습니다. 로그인과 마음 라운지의 기존 Firebase 연결은 유지되므로, 이 테스트에서는 토론·확장 프로그램 기능을 사용하세요.

자동 검증:

```sh
npm test
cd worker
npm test
cd ..
npx playwright install chromium
npm run test:extension
```

확장 프로그램 브라우저 테스트는 별도 테스트용 브라우저 프로필을 사용합니다. Firebase와 AI 응답은 모의 응답이며 운영 계정·댓글·토론을 만들지 않습니다. 유튜브 입력창 테스트도 유튜브 형태의 가상 페이지를 사용합니다. 실제 유튜브 계정에서의 로그인·입력창 동작과 실제 AI 응답 품질은 따로 확인해야 합니다. 일반 웹 테스트는 설치된 Chrome을 사용합니다.

## 공개 배포

현재는 개발자 모드에서 설치하는 버전입니다. Chrome Web Store에 공개하려면 개발자 계정에서 등록·심사를 진행하고, 데이터 수집·AI 전송·권한 용도를 설명하는 개인정보처리 안내를 준비해야 합니다. 스토어 등록은 자동으로 진행하지 않습니다.
